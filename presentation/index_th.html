โจทย์ #545

Baby DPDK

แต่แพ็กเก็ตเครือข่ายของฉันหายไปไหนหมด?

ในโจทย์ข้อนี้ เราขอเชิญชวนคุณมาสนุกกับ DPDK

คุณสามารถกู้คืนเนื้อหาของแพ็กเก็ตเครือข่ายที่ได้รับบนอินเทอร์เฟซเครือข่ายได้หรือไม่?

หมายเหตุ:

  • เพื่อให้ปุ่ม Ctrl-C ใช้งานได้ คุณสามารถใช้คำสั่ง stty -cooked -echo ในเทอร์มินัลของคุณหลังจากส่งการเชื่อมต่อไปยังโจทย์ที่ทำผ่าน nc ไปยังพื้นหลัง
  • ในการจำลองโจทย์แบบโลคอล: แตกไฟล์อาร์ไคฟ์ด้วย tar xf babydpdk.tar.xz รันคอนเทนเนอร์ Docker ด้วย docker compose up --build เชื่อมต่อไปยังโจทย์โลคอลด้วย nc localhost 4000
  • ในการเชื่อมต่อไปยังเครื่อง ให้ใช้รหัสผ่าน “user”
