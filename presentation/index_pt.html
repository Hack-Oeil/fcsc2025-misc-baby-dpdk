Desafio #545

Baby DPDK

Mas para onde foram os meus pacotes de rede?

Neste desafio, propomos que jogue com o DPDK.

Consegue encontrar o conteúdo dos pacotes de rede recebidos na interface de rede?

Observações:

  • Para ter um Ctrl-C funcional, você pode usar stty -cooked -echo no seu terminal depois de colocar em segundo plano a sua conexão com o desafio feita com nc.
  • Para reproduzir o desafio localmente: Descompacte o arquivo com tar xf babydpdk.tar.xz. Inicie o contêiner Docker com docker compose up --build. Conecte-se ao desafio local com nc localhost 4000.
  • Para se conectar à máquina, use a senha “user”

Arquivo a ser analisado:
