Челлендж #545

Baby DPDK

Куда же делись мои сетевые пакеты?

В этом задании мы предлагаем вам поработать с DPDK.

Сможете ли вы восстановить содержимое сетевых пакетов, полученных на сетевом интерфейсе?

Примечания:

  • Чтобы работал Ctrl-C, вы можете использовать команду stty -cooked -echo в терминале после отправки соединения с челленджем, установленного через nc, в фоновый режим.
  • Для локального воспроизведения задания: Распакуйте архив с помощью tar xf babydpdk.tar.xz. Запустите Docker-контейнер с помощью docker compose up --build. Подключитесь к локальному заданию с помощью nc localhost 4000.
  • Для входа на машину используйте пароль «user»
